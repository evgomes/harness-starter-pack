# Claude Code instructions for this repository

Read [AGENTS.md](AGENTS.md) and [en/README.md](en/README.md) before changing the starter pack. The `en/` package is the current source of truth for reusable guidance. Use only the relevant skill under `en/skills/`; brainstorming is optional. Keep new reusable assets inside the appropriate language package and update its catalog when needed.

## For consuming projects

Harness adapters intended to be copied into target repositories are in `en/harnesses/`. Do not treat this library's starter templates as verified agreements for another repository.
