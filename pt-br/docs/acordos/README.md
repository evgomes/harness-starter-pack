# Acordos de engenharia

Copie os cinco acordos para docs/acordos/ e substitua as perguntas por decisões e evidências verificadas no repositório. Estes arquivos são pontos de partida, não afirmações sobre um projeto ainda não inspecionado.

| Acordo | Responsabilidade |
|---|---|
| [Arquitetura](arquitetura.md) | Registrar componentes, responsabilidades, limites e decisões arquiteturais. |
| [Dependências](dependencias.md) | Inventariar pacotes e registrar políticas e revisões. |
| [Convenções](convencoes.md) | Definir convenções locais e princípios de design aplicáveis. |
| [Workflow](workflow.md) | Orientar o fluxo reutilizável de trabalho assistido por IA. |
| [Qualidade e segurança](qualidade-e-seguranca.md) | Definir verificações, critérios, responsáveis e evidências. |

As decisões verificadas do projeto prevalecem. Mantenha o workflow como padrão reutilizável, adaptando-o somente quando o processo documentado exigir.
